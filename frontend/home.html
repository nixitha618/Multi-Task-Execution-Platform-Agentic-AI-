Enterprise Protection & SQLite Vault

Zero-Trust Security & Credential Vault

Every credential, user preference, and execution trace is secured in our local SQLite database with 12-round salted bcrypt encryption and strict input validation rules.

🔐

12-Round Salted Bcrypt

Passwords are hashed with Blowfish-derived salt rounds before storage. Plaintext passwords are never logged, cached, or written to disk.

🛡️

Strict Input Validation Rules

Robust constraints enforce RFC-compliant emails, minimum 8-character passwords with uppercase, lowercase, numbers, and special symbols, plus SQL injection safeguards.

💾

Direct SQLite Database Connection

User accounts, personalized memory keys, execution audit logs, and schedule jobs are persisted directly in local ACID SQLite tables.

🚪

Client-Side Auth Guards

Direct URL navigation to protected workspace routes (/dashboard) is automatically guarded and redirected to /login if unauthenticated.
